# Расписание группы 185 ЭС

Одностраничный сайт с расписанием: недели 1 и 2, пары с 8:30, внеурочка.
Базовое расписание лежит в `schedule.json`, временные замены по конкретным датам —
в `overrides.json`. Оба файла загружаются при каждом открытии страницы, поэтому после
замены файла в репозитории новое расписание сразу видят все.

Над расписанием показывается виджет «сейчас идёт / следующая пара» — он считает
по фактическому времени пар на сегодня, с учётом замен.

## Публикация на GitHub Pages

1. Создайте репозиторий и залейте в него файлы:
   `index.html`, `style.css`, `script.js`, `schedule.json`, `overrides.json`
   (`serve.py` и `start.cmd` нужны только для локального запуска — их можно не добавлять).
2. В репозитории: **Settings → Pages → Build and deployment**
   → Source: **Deploy from a branch** → Branch: **main**, папка **/(root)** → Save.
3. Через минуту сайт откроется по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Все пути относительные (`./style.css`, `./script.js`, `./schedule.json`),
поэтому сайт работает и в подпапке репозитория, и локально.

## Как обновлять расписание

1. Откройте сайт и войдите в режим администратора:
   - **5 быстрых кликов** по бейджу «185» в левом верхнем углу, или
   - добавьте к адресу `?admin=1`.
2. Появится кнопка **«Редактировать»** и нижняя панель управления.
3. В режиме правки у каждой пары есть **✎** и **✕**, внизу дня — **«+ пара»** и **«+ внеурочка»**.
   В окне правки время, преподаватель и аудитория подставляются сами по названию предмета.
4. Нажмите **«Сохранить»** — правки лягут в черновик браузера и переживут перезагрузку.
   Черновик видят только вы в режиме администратора; студентам он не показывается.
5. Для публикации нажмите **«Скачать JSON»** (базовое расписание) и/или
   **«Скачать замены»** (`overrides.json`), замените файлы в репозитории и сделайте commit.

Страница запрашивает `./schedule.json` с параметром `?v=<время>` и `cache: "no-store"`,
так что кэш не помешает: студенты увидят замены после обновления страницы.

Правки сохраняются кнопкой **«Сохранить»** в черновик браузера (localStorage) и
переживают перезагрузку. Черновик действует только в режиме администратора на этом
устройстве — посетители всегда получают данные из файлов репозитория. «Вернуть из файла»
удаляет черновик и перечитывает `schedule.json` с `overrides.json`.

Если закрыть вкладку с несохранёнными (не «Сохранёнными») правками, браузер предупредит.

## Время пар (звонки)

| Пара | Время |
|------|-------|
| 1 | 8:30–10:00 |
| 2 | 10:10–11:40 |
| 3 | 12:20–13:50 |
| 4 | 14:00–15:30 |

Большая перемена одна — между 2-й и 3-й парой.

- если **последняя** пара дня — математика (Пн, Ср, а также Чт с прикладной математикой),
  третья пара идёт **12:10–13:40**;
- как только в таком дне появляется 4-я пара, математика перестаёт быть последней:
  третья автоматически становится **12:20–13:50**, четвёртая — 14:00–15:30;
- в субботу большая перемена короче на 20 минут: третья пара **12:00–13:30**,
  четвёртая — **13:40–15:10**.

При правке пары время, преподаватель и аудитория подставляются по названию предмета:
достаточно начать вводить «матем», «англ», «физра», «общество», «опд» и т.п.

## Замены на один день (overrides.json)

Замены не трогают базовое расписание: если для даты есть запись в `overrides.json`,
сайт показывает пары на этот день целиком из неё, а остальные дни — из `schedule.json`.

```json
{
  "version": 1,
  "overrides": {
    "2026-11-24": {
      "note": "1 пара отменена, занимаемся со 2-й в 10:10",
      "pairs": [
        { "n": 2, "time": "10:10–11:40", "subject": "Физика", "teacher": "Добшиков А.Е", "room": "301" },
        { "n": 3, "time": "12:20–13:50", "subject": "История", "teacher": "Медвецкая М.В", "room": "310" }
      ]
    }
  }
}
```

Правила:

- ключ — дата в формате `YYYY-MM-DD`;
- `pairs` заменяет список пар на этот день полностью. Чтобы отменить 1-ю пару,
  просто не включайте её в список; чтобы добавить 4-ю — добавьте объект с `n: 4`
  и своим временем;
- `note` — короткое пояснение, оно показывается в карточке дня;
- `extras` можно указать явно, иначе берутся внеурочки из базового дня
  (например, «Разговоры о важном» останутся);
- замены полностью редактируются из админки: в режиме правки нажмите
  **«заменить день»**, и день начнёт жить отдельно от базы — пары добавляются,
  меняются и удаляются так же, как обычные. Кнопка **«убрать замену»** возвращает
  базовое расписание, а ✎ рядом с пояснением меняет текст заметки;
- после правок нажмите **«Скачать замены»** — получится `overrides.json`.

В репозитории уже лежат два тестовых примера:

- **24.11.2026** — отменена 1-я пара, занятия со 2-й в 10:10;
- **26.11.2026** — добавлена 4-я пара (информатика, 14:00–15:30).

Удалите эти блоки из `overrides.json`, когда они станут не нужны.

## Админ-панель

| Кнопка | Что делает |
|--------|------------|
| Редактировать | включает режим правки пар и внеурочки |
| Сохранить | сохраняет черновик в браузере (переживает перезагрузку) |
| Пересчитать время | расставляет время пар по звонкам из `schedule.json` |
| Скопировать неделю | переносит данные текущей недели в соседнюю |
| Очистить неделю | удаляет все пары и внеурочку текущей недели |
| Скачать JSON | сохраняет `schedule.json` (базовое расписание) |
| Скачать замены | сохраняет `overrides.json` (замены по датам) |
| Загрузить JSON | подставляет ранее скачанный файл в черновик |
| Вернуть из файла | перезагружает `schedule.json` и `overrides.json` |
| Выйти | выключает режим администратора |

Обычные посетители видят только расписание: кнопки правки и панель скрыты.

## Структура schedule.json

```json
{
  "version": 1,
  "group": "185 ЭС",
  "short": "185",
  "specialty": "13.02.13",
  "semester": "1 семестр 2026–2027",
  "refMonday": "2026-11-23",
  "bells": {
    "pairs": ["8:30–10:00", "10:10–11:40", "12:20–13:50", "14:00–15:30"],
    "third": { "normal": "12:20–13:50", "mathLast": "12:10–13:40", "saturday": "12:00–13:30" },
    "fourth": { "normal": "14:00–15:30", "saturday": "13:40–15:10" },
    "mathPattern": "математик"
  },
  "weeks": {
    "1": {
      "mon": {
        "extras": [{ "time": "8:00", "title": "Разговоры о важном", "place": "" }],
        "pairs": [
          { "n": 1, "time": "8:30–10:00", "subject": "Математика", "teacher": "Мишина В.Ю", "room": "122" }
        ]
      }
    }
  }
}
```

- `refMonday` — понедельник первой недели; от него считается чередование недель.
- `bells.pairs` — время 1–4-й пар по умолчанию.
- `bells.third` — особые случаи для третьей пары: `mathLast` (дни, где последняя
  пара — математика), `saturday` (короткая большая перемена).
- `bells.fourth` — время четвёртой пары: обычное и субботнее.
- `weeks.1` и `weeks.2` — дни `mon`…`sat`, у каждого массивы `extras` и `pairs`.
- В паре можно указать `alt` для второй подгруппы:
  `"alt": { "subject": "Иностранный язык", "teacher": "…", "room": "306/312" }`.

## Локальный запуск

```powershell
python serve.py
```

или двойной клик по `start.cmd`. Адрес: <http://127.0.0.1:8000/>.

Открывать сайт нужно через сервер: при `file://` браузер блокирует загрузку
`schedule.json`, и страница покажет ошибку.

## Файлы

- `index.html` — разметка
- `style.css` — оформление, живой фон, печать
- `script.js` — загрузка данных, недели, замены по датам, виджет, админ-редактор
- `schedule.json` — базовое расписание (недели 1 и 2)
- `overrides.json` — временные замены по датам
